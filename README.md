# Fuegos Artificiales Cepeda 🎆

![Banner Cepeda Fireworks](assets/images/cover.webp)

## 🎯 Propuesta de Valor
Este proyecto es la presencia digital de **Fuegos Artificiales Cepeda**, un negocio familiar ecuatoriano especializado en la distribución mayorista de pirotecnia de alta rotación. La plataforma está diseñada para facilitar el trato directo entre el dueño y comerciantes locales, eliminando intermediarios y garantizando precios competitivos para la temporada.

---

## ✨ Características de la Plataforma

### 💎 Diseño Temático y Moderno
- **Experiencia de Usuario (UX):** Interfaz oscura elegante con efectos de *glassmorphism* y gradientes que simulan el resplandor de la pirotecnia.
- **Interactividad:** Sistema de "chispas" dinámicas al hacer clic y animaciones suaves de entrada al hacer scroll.
- **Portada de Alto Impacto:** Diseño estilo banner (tipo Facebook) que resalta la identidad del negocio de forma inmediata.

### 📱 Optimización Técnica
- **Responsive Design:** Adaptado perfectamente para dispositivos móviles, tablets y computadoras.
- **SEO de Alto Nivel:** Configurado con meta-etiquetas de búsqueda, Open Graph (para compartir en WhatsApp/Facebook) y jerarquía semántica para buscadores.
- **Rendimiento:** Implementación de *Lazy Loading* y priorización de carga para asegurar una navegación rápida incluso en conexiones móviles.
- **Accesibilidad:** Contraste de colores optimizado (estándar WCAG) y navegación lógica para una mejor legibilidad.

---

## 🛠️ Tecnologías Utilizadas
- **HTML5:** Estructura semántica y moderna.
- **CSS3:** Flexbox, CSS Grid, variables personalizadas y animaciones avanzadas.
- **JavaScript (Vanilla):** Lógica personalizada para efectos visuales, header dinámico e interacciones de usuario.
